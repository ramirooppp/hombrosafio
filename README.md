# Hombrosafío 4

## Descargar el mod manualmente

**Versión actual: 0.32.75**

### [Descargar ZIP](https://github.com/ramirooppp/hombrosafio/releases/download/mod-v0.32.75/hombrosafio-0.32.75.zip)

### [Descargar JAR](https://github.com/ramirooppp/hombrosafio/releases/download/mod-v0.32.75/hombrosafio-0.32.75.jar)

[Ver la página de la versión](https://github.com/ramirooppp/hombrosafio/releases/tag/mod-v0.32.75)

Si la descarga del JAR no empieza o se corta, probá el ZIP.

1. Descomprimí el ZIP y copiá `hombrosafio-0.32.75.jar` a la carpeta `mods` de tu instalación.
2. Retirá el `hombrosafio-0.32.xx.jar` anterior para no tener dos versiones. Conservá los demás mods del pack.
3. No pongas el ZIP dentro de `mods`: usá el JAR que contiene.

El archivo contiene **solo el mod de Hombrosafío**. Para instalar todo el pack o actualizarlo automáticamente, usá el launcher.

Minecraft **26.3**, Fabric **0.19.5** y Java **25**.

Servidor: **nodousa.xalfax.online:25611**

## Cambios de esta versión

Nautilos más pequeños, 20% más rápidos y ataques cada segundo; conservan un corazón de daño contra ancestral completa con Protección IV. Armaduras ancestral y glebanoide con el doble de durabilidad original, manteniendo a Gleba por encima de ancestral. Incluye las correcciones de nave sin piloto y control de acompañantes.
