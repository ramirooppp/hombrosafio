## Descargar el mod manualmente

**Versión actual: 0.32.76**

### [Descargar ZIP](https://github.com/ramirooppp/hombrosafio/releases/download/mod-v0.32.76/hombrosafio-0.32.76.zip)

### [Descargar JAR](https://github.com/ramirooppp/hombrosafio/releases/download/mod-v0.32.76/hombrosafio-0.32.76.jar)

[Ver la página de la versión](https://github.com/ramirooppp/hombrosafio/releases/tag/mod-v0.32.76)

Si la descarga del JAR no empieza o se corta, probá el ZIP.

1. Descomprimí el ZIP y copiá `hombrosafio-0.32.76.jar` a la carpeta `mods` de tu instalación.
2. Retirá el `hombrosafio-0.32.xx.jar` anterior para no tener dos versiones. Conservá los demás mods del pack.
3. No pongas el ZIP dentro de `mods`: usá el JAR que contiene.

El archivo contiene **solo el mod de Hombrosafío**. Para instalar todo el pack o actualizarlo automáticamente, usá el launcher.
