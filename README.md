# Hombrosafío 4

## Descargar el mod manualmente

**Versión actual: 0.32.78**

### [Descargar ZIP](https://github.com/ramirooppp/hombrosafio/releases/download/mod-v0.32.78/hombrosafio-0.32.78.zip)

### [Descargar JAR](https://github.com/ramirooppp/hombrosafio/releases/download/mod-v0.32.78/hombrosafio-0.32.78.jar)

[Ver la página de la versión](https://github.com/ramirooppp/hombrosafio/releases/tag/mod-v0.32.78)

Si la descarga del JAR no empieza o se corta, probá el ZIP.

1. Descomprimí el ZIP y copiá `hombrosafio-0.32.78.jar` a la carpeta `mods` de tu instalación.
2. Retirá el `hombrosafio-0.32.xx.jar` anterior para no tener dos versiones. Conservá los demás mods del pack.
3. No pongas el ZIP dentro de `mods`: usá el JAR que contiene.

El archivo contiene **solo el mod de Hombrosafío**. Para instalar todo el pack o actualizarlo automáticamente, usá el launcher.

Minecraft **26.3**, Fabric **0.19.5** y Java **25**.

## Cambios de esta versión

Agrega Build Battle al gulag y al modo evento: temas elegidos por el administrador en cada ronda, parcelas privadas, materiales creativos, votaciones de jugadores y espectadores y puntos acumulados. Los espectadores pueden moverse libremente. Los inventarios temporales de gulags y eventos no cuentan para las misiones de supervivencia. Mejora el arco glebanoide, conserva su textura original y ajusta su daño a 23 puntos con Poder V.
